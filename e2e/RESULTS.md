## 확인한 동작

- Desktop CLI가 별도 desktop 프로필에 패키지를 설치했습니다. Agent Teams를 활성화한 뒤 기존 네이티브 Agent 세션 4개를 재사용했습니다.
- 전체 승인 전에는 원본 작업 0건, 승인 후에는 3건을 확인했습니다. Desktop Host의 Chromium 화면에서 작업 3개의 완료 상태와 결과를 확인했습니다.
- 미인증 호출은 HTTP 401, Desktop 업데이트 잠금 중 새 실행은 HTTP 503으로 거절됐습니다. Desktop Host는 종료 전에 진행 중인 턴을 감지했고 재시작 후 중단 상태를 보존했습니다.
- 작업에서 허용된 DSH 도구가 별도의 네이티브 작업을 만들려고 시도했을 때 거절됐습니다. 드라이브 상대 경로·대체 데이터 스트림·장치명·작업 공간 밖 링크도 거절됐습니다.
- 방 전체 중지로 같은 방의 채팅·워크플로우 실행·대기열과 미승인 배분안을 중지했습니다. 0.3.1 체크포인트는 같은 DSH 작업 ID와 같은 시도에서 이어졌습니다.
- 별도 어댑터로 원본 보드 없는 실행과 도구 권한 기능이 없는 경우의 차단, 다른 어댑터 출처의 실행 복구 거절을 검사했습니다.

공식 Desktop Host를 Linux에서 Node 모드로 실행했습니다. 테스트 모델을 사용했습니다. Windows/macOS 설치 파일과 Electron 셸, 실제 모델·장비, 다른 Harness 실연동은 미검증입니다.

첫 Chromium 회귀에서 답장과 워크플로우 편집 도중 화면이 DSH 기본 화면으로 돌아가 2건이 타임아웃했습니다. 동일 패키지로 해당 그룹을 각각 다시 실행해 전 케이스가 통과했습니다. 화면 전환의 원인은 확정하지 못했습니다.
